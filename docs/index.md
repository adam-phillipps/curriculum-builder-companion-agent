# Curriculum Builder Companion Agent

An AI-powered curriculum building and analysis platform that helps educators create, manage, and optimize learning content using advanced agentic workflows.

## 🎯 Our Mission

We're building an open-source platform that makes learning more efficient by:

- **Eliminating Learning Waste**: Skip unnecessary content and focus on what you actually need to reach your goals
- **Personalizing Learning Paths**: AI-powered gap analysis creates custom learning journeys
- **Empowering Educators**: Tools to build better content and understand learner progress
- **Keeping Education Open**: Free, community-driven platform that prevents commercial exploitation

## ✨ Key Features

### 🎯 Smart Learning Outcomes
Set learning goals in natural language and let AI find similar objectives, suggest prerequisites, and map learning domains.

### 📊 Intelligent Progress Tracking  
Track both completion and comprehension with visual learning graphs that show your journey and identify knowledge gaps.

### 🤖 AI-Powered Content Building
Create learning content with embedded similarity search, automated metadata extraction, and gap analysis integration.

### 📈 Interactive Learning Graphs
Visualize learning pathways with hierarchical or centered layouts, filter by progress, and focus on specific learning objectives.
